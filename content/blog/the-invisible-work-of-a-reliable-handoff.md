## One trail from decision to work

The goal is not more documentation. It is one clear path from the decision that was made to the work that happens next.

## Name every final file

Final means final. Every handover folder has one version of each asset, named clearly, with a short note on where it is used.

### Hand over the accounts, not just the files

Domains, hosting, the CMS and the agent platform should all sit in the client's own accounts before the project ends. Nobody should need to message us to change a headline.

## Record a short walkthrough

A ten minute screen recording explaining how to update the site or the agent saves hours of questions later, and it is the part clients thank us for most.
